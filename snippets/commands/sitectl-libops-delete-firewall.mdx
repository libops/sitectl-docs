Delete a firewall rule for an organization, project, or site. Specify one of `--organization-id`, `--project-id`, or `--site-id`.

```bash
sitectl libops delete firewall <rule-id>
```

| Flag | Default | Description |
|------|---------|-------------|
| `--organization-id` |   | Organization ID |
| `--project-id` |   | Project ID |
| `--site-id` |   | Site ID |
| `-y, --yes` | `false` | Skip confirmation prompt |
