Checkout a site environment repository locally

```bash
sitectl libops checkout <site-id> [directory]
```

| Flag | Default | Description |
|------|---------|-------------|
| `--context-name` |   | sitectl context name |
| `--default` | `true` | Set the updated context as current |
| `--plugin` |   | sitectl plugin name; defaults from site application type |
| `--project-dir` |   | Local or remote compose project directory |
| `--ssh-host` |   | SSH hostname; defaults from the site managed domain |
| `--ssh-key` |   | Path to SSH private key |
| `--ssh-port` | `22` | SSH port |
| `--ssh-user` | `deploy` | SSH username |
| `--update-context` | `false` | Update a sitectl context after checkout |
