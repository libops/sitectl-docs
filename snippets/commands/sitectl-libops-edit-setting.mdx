Update a setting value for an organization, project, or site. Specify one of `--organization-id`, `--project-id`, or `--site-id`.

```bash
sitectl libops edit setting <setting-id>
```

| Flag | Default | Description |
|------|---------|-------------|
| `--organization-id` |   | Organization ID |
| `--project-id` |   | Project ID |
| `--site-id` |   | Site ID |
| `--value` |   | Setting value |
