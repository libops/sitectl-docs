Create a new site

```bash
sitectl libops create site
```

| Flag | Default | Description |
|------|---------|-------------|
| `--application-type` |   | Type of application (drupal, ojs, wordpress, omeka-classic, omeka-s, archivesspace, islandora) |
| `--compose-file` | `compose.yaml` | Docker compose file name |
| `--compose-path` | `.` | Repository-relative directory containing this site's Docker Compose file |
| `--github-ref` |   | GitHub reference (e.g., heads/main, tags/v1.0) |
| `--github-repository` |   | Supported LibOps template repository URL used to create or attach the managed customer repository (required) |
| `--init-cmd` | `[]` | Commands to run on initial setup |
| `--name` |   | Site name (required) |
| `--port` | `80` | Port the application listens on |
| `--project-id` |   | Project ID (required) |
| `--rollout-cmd` | `[]` | Commands to run during rollout |
| `--up-cmd` | `[]` | Commands to start containers |
