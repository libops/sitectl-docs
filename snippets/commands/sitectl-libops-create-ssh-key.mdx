Add an SSH public key to your LibOps account

```bash
sitectl libops create ssh-key
```

| Flag | Default | Description |
|------|---------|-------------|
| `--account-id` |   | Account ID; defaults to the authenticated account |
| `--name` |   | SSH key name |
| `--public-key` |   | SSH public key content |
| `--public-key-file` |   | Local public key file to authorize for LibOps SSH access. |
