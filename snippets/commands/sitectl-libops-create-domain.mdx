Create a custom domain for a site

```bash
sitectl libops create domain
```

| Flag | Default | Description |
|------|---------|-------------|
| `--domain` |   | Domain hostname |
| `--edge-action` | `allow` | Edge action: allow, challenge, or block |
| `--site-id` |   | Site ID |
| `--status` | `active` | Domain status: active, pending, suspended, or blocked |
| `--success-log-sample-rate` |   | Success log sample rate between 0 and 1 |
| `--tier` | `standard` | Domain service tier |
