Create a secret for an organization, project, or site. Specify one of `--organization-id`, `--project-id`, or `--site-id`.

```bash
sitectl libops create secret
```

| Flag | Default | Description |
|------|---------|-------------|
| `--name` |   | Secret name (required) |
| `--organization-id` |   | Organization ID |
| `--project-id` |   | Project ID |
| `--site-id` |   | Site ID |
| `--value` |   | Secret value |
| `--value-file` |   | Local file whose complete contents become the new secret value. |
