Create a setting for an organization, project, or site. Specify one of `--organization-id`, `--project-id`, or `--site-id`.

```bash
sitectl libops create setting
```

| Flag | Default | Description |
|------|---------|-------------|
| `--description` |   | Setting description |
| `--editable` | `true` | Whether users may edit the setting |
| `--key` |   | Setting key |
| `--organization-id` |   | Organization ID |
| `--project-id` |   | Project ID |
| `--site-id` |   | Site ID |
| `--value` |   | Setting value |
