SSH into a site environment

```bash
sitectl libops ssh <site-id> [-- ssh-args...]
```

| Flag | Default | Description |
|------|---------|-------------|
| `--ssh-host` |   | SSH hostname override; defaults to the exact hostname returned by the LibOps API |
| `--ssh-key` |   | Local private key used to authenticate the SSH session to the managed host. |
| `--ssh-port` | `22` | SSH port |
| `--ssh-user` | `deploy` | SSH username |
