Create a new API key

```bash
sitectl libops create apikey
```

| Flag | Default | Description |
|------|---------|-------------|
| `--description` |   | API key description |
| `--name` |   | API key name (required) |
| `--save` | `false` | Save the created API key to ~/.sitectl/key for future CLI requests |
| `--scopes` | `[]` | API key scopes (e.g., organization:read, project:write) |
