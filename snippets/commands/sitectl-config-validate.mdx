Validate sitectl context configuration and access

```bash
sitectl config validate [context-name]
```

| Flag | Default | Description |
|------|---------|-------------|
| `--all` | `false` | Validate configuration and target access for every saved context. |
| `--format` | `section` | Report output format: section, table, json, or yaml |
| `--site` |   | Validate every environment context belonging to this logical site. |
