Update a secret value for an organization, project, or site. Specify one of `--organization-id`, `--project-id`, or `--site-id`.

```bash
sitectl libops edit secret <secret-id>
```

| Flag | Default | Description |
|------|---------|-------------|
| `--organization-id` |   | Organization ID |
| `--project-id` |   | Project ID |
| `--site-id` |   | Site ID |
| `--value` |   | Secret value |
| `--value-file` |   | Local file whose complete contents replace the existing secret value. |
