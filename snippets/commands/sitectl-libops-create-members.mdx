Add a member to an organization, project, or site. Specify one of `--organization-id`, `--project-id`, or `--site-id`.

```bash
sitectl libops create members
```

| Flag | Default | Description |
|------|---------|-------------|
| `--account-id` |   | Account email to add (required) |
| `--organization-id` |   | Organization ID |
| `--project-id` |   | Project ID |
| `--role` | `read` | Role (owner, developer, read) |
| `--site-id` |   | Site ID |
