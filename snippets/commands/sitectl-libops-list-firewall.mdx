List firewall rules. Optionally filter by `--organization-id`, `--project-id`, or `--site-id`. If no filter is specified, lists all firewall rules.

```bash
sitectl libops list firewall
```

| Flag | Default | Description |
|------|---------|-------------|
| `--organization-id` |   | Filter by organization ID |
| `--project-id` |   | Filter by project ID |
| `--site-id` |   | Filter by site ID |
