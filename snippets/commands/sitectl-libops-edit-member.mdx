Update a member role for an organization, project, or site. Specify one of `--organization-id`, `--project-id`, or `--site-id`.

```bash

```

| Flag | Default | Description |
|------|---------|-------------|
| `--organization-id` |   | Organization ID |
| `--project-id` |   | Project ID |
| `--role` |   | Role (owner, developer, read) |
| `--site-id` |   | Site ID |
