---
title: Traefik TLS
description: TLS mode documentation now lives with the core Traefik service commands.
---

TLS mode selection for Islandora uses the shared Traefik service command surface:

```bash
sitectl traefik tls http
sitectl traefik tls mkcert --domain local.example.test
sitectl traefik tls letsencrypt --email ops@example.org
sitectl traefik tls self-managed --cert-file ./cert.pem --key-file ./privkey.pem
```

See [Traefik service commands](/plugins/traefik) for supported TLS modes, Let's Encrypt settings, certificate inputs, context override behavior, and ingress status.
