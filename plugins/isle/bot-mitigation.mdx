description: Bot mitigation documentation now lives with the core Traefik service commands.
---

Bot mitigation for Islandora uses the shared Traefik service command surface:

```bash
sitectl traefik bot-mitigation on --turnstile-site-key "$TURNSTILE_SITE_KEY" --turnstile-secret-key "$TURNSTILE_SECRET_KEY"
sitectl traefik bot-mitigation off
```

See [Traefik service commands](/plugins/traefik) for Turnstile keys, local captcha-protect plugin source behavior, and app-specific router wiring.
