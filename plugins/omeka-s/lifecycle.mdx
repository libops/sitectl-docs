All LibOps application plugins expose the same <Compose /> lifecycle commands:

```bash
sitectl omeka-s build
sitectl omeka-s init
sitectl omeka-s up
sitectl omeka-s down
sitectl omeka-s status
sitectl omeka-s logs
sitectl omeka-s rollout
```

These delegate to the template Makefile where appropriate, so local development, production rollout, and VM automation all use the same operational contract.

Use `init` when you intentionally want to create or reset the environment's required secrets and volumes. Use `up` for the normal start path.
