---
title: resources
description: Read common Omeka S resources through shortcut commands.
---

Use resource commands for common read operations:

```bash
sitectl omeka-s items
sitectl omeka-s item-sets
sitectl omeka-s media
sitectl omeka-s vocabularies
sitectl omeka-s resource-classes
sitectl omeka-s properties
sitectl omeka-s resource-templates
sitectl omeka-s sites
sitectl omeka-s site-pages
sitectl omeka-s modules
```

Pass an ID to read a single record:

```bash
sitectl omeka-s media 12
```

These shortcuts accept the same read flags as `api get`, including `--url`, `--identity`, `--credential`, and repeated `--query name=value` filters.
