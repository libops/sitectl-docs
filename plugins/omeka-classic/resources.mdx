Use resource commands for common read operations:

```bash
sitectl omeka-classic items
sitectl omeka-classic collections
sitectl omeka-classic files
sitectl omeka-classic tags
sitectl omeka-classic users
sitectl omeka-classic element-sets
sitectl omeka-classic elements
sitectl omeka-classic item-types
sitectl omeka-classic site
```

Pass an ID to read a single record:

```bash
sitectl omeka-classic items 12
```

These shortcuts accept the same read flags as `api get`, including `--url`, `--key`, and repeated `--query name=value` filters.
